# Сложно сосредоточиться 👀

Одностраничное веб-приложение, которое помогает разобраться с причинами рассеянности и подобрать
привычки для возвращения внимания. Показывает современную вёрстку с адаптивными темами и бережным
отношением к пользовательскому опыту.

## ✨ Основные возможности

- Темный, светлый и автоматический режимы с сохранением выбора пользователя в `localStorage`
- Адаптивная типографика и сетка, корректно работающая на экранах от телефона до монитора
- Семантическая структура HTML для доступности и чтения с экранных дикторов
- Карточки с проверенными ссылками и практическими рекомендациями
- Декор и анимации, которые поддерживают тему концентрации
- Поддержка системного `prefers-color-scheme` и плавное переключение тем без перезагрузки

## 🛠️ Используемые технологии

- **Разметка и стили:** HTML5, CSS3, сетки Grid и Flex, переменные CSS
- **Поведение:** JavaScript, работа с DOM, `localStorage`, управление классами
- **Структура стилей:** методология БЭМ, темы `dark/light/auto`, единая система переменных
- **Среда разработки:** Node.js, NPM Scripts, ESLint, Stylelint, Prettier
- **Ресурсы:** подключение шрифтов, оптимизированные изображения `PNG` и `SVG`, набор favicon

## 🚀 Быстрый старт

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/IrinaRyazanskaya/hard-to-focus.git
   cd hard-to-focus
   ```

2. Установите зависимости (нужен Node.js версии 22+):

   ```bash
   npm install
   ```

3. Запустите локальный сервер для просмотра вёрстки:

   ```bash
   npm run serve
   ```

4. Откройте страницу в браузере по адресу, который появится в терминале (по умолчанию
   `http://localhost:3000`), либо просто откройте `index.html` напрямую.

- Конфигурация линтеров (ESLint, Stylelint) и автоформатирования (Prettier) в npm-скриптах

## 💡 Технические задачи и решения

- Сохранение выбранной темы: реализовано через `localStorage` и запуск нужной темы при загрузке,
  чтобы пользователь сразу видел знакомый режим без мерцаний
- Три варианта оформления: дизайн-переменные вынесены в `variables.css`, а изменения для тем
  разделены по файлам `dark.css` и `light.css`, что упрощает развитие проекта
- Адаптивные заголовки без медиа-запросов: использована функция `clamp()` для плавного изменения
  размеров текста и поддержания читаемости
